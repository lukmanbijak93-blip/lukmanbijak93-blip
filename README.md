## About Me

Saya **Lukman Bijak Bestari**, developer sistem bisnis. Saya membangun aplikasi operasional, menghubungkan sistem yang berbeda, dan merapikan data agar tim bekerja lebih sederhana.

Pengalaman saya mencakup aplikasi untuk **importir, distributor, manufaktur, yayasan pendidikan, dan grup usaha multi-perusahaan**: dari **ERP back-office**, **integrasi sistem akuntansi, pajak, dan akademik**, **konsolidasi keuangan**, hingga **workflow persetujuan** dan **otomatisasi**. Saya juga mendampingi dan melatih tim saat sistem mulai dipakai.

## How I Work

<picture>
  <source media="(max-width: 600px)" srcset="./assets/workflow-mobile.svg" />
  <img src="./assets/workflow.svg" width="100%" alt="Alur kerja: memahami proses bisnis, merancang integrasi, mengotomatisasi pekerjaan, lalu mengevaluasi laporan." />

1. **Pahami proses** — petakan kebutuhan, alur kerja, dan sumber data.
2. **Hubungkan sistem** — susun struktur data dan integrasi yang sesuai.
3. **Otomatisasi pekerjaan** — terapkan validasi dan kurangi langkah berulang.
4. **Evaluasi hasil** — gunakan laporan serta masukan tim untuk perbaikan.
